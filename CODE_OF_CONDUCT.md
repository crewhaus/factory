# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, with one project-specific reporting address.

Use the verbatim text of the Contributor Covenant 2.1 from https://www.contributor-covenant.org/version/2/1/code_of_conduct/.

In Week 1 of the migration:

```bash
curl -o CODE_OF_CONDUCT.md https://raw.githubusercontent.com/EthicalSource/contributor_covenant/main/content/version/2/1/code_of_conduct.md
```

Then edit the "Enforcement" section to point to **conduct@crewhaus.ai** as the reporting address.

## Reporting

Reports go to **conduct@crewhaus.ai**.

Reports are handled by the project lead unless the project lead is the subject. In that rare case, reports can be sent to a trusted third-party reviewer named in advance — at launch this is unfilled because the project has a single project lead; we will name a backup reviewer by Day 180 (see `decisions/008-cross-promotion-strategy.md` and `GOVERNANCE.md`).

We will acknowledge reports within 3 business days. We aim to take action within 14 days. Confidentiality is maintained to the extent possible.

## Enforcement guidelines

We follow the Contributor Covenant 2.1's four-step enforcement ladder:

1. Correction — private written warning
2. Warning — formal warning with consequences for continued behavior
3. Temporary ban — temporary ban from project participation
4. Permanent ban — permanent ban from project participation

The project lead has final discretion in applying these steps based on context.

## Why a Code of Conduct

CrewHaus exists to build useful software with a healthy community. A clear Code of Conduct sets the expectation that the project is welcoming to first-time contributors and seasoned engineers alike — and that disrespectful behavior gets addressed promptly.

Most projects never have to invoke the enforcement ladder. We hope CrewHaus is one of them. The policy exists for the cases where it's needed.
